## 完整问答链路图

```mermaid
sequenceDiagram
    actor U as 用户
    participant F as 前端 SPA
    participant API as FastAPI
    participant RL as 频率限制
    participant TM as 聊天任务管理器
    participant AG as LangGraph Agent
    participant EM as Embedding 服务
    participant QD as Qdrant 向量库
    participant LLM as 大语言模型
    participant CP as LangGraph Checkpointer

    Note over U,CP: 第1步：用户发起对话
    U->>F: 输入问题
    F->>API: POST /chat/invoke {query}

    Note over API,RL: 请求校验
    API->>API: 校验 query ≤ 500 字
    API->>RL: check_and_increment(user_id)
    RL->>API: OK（未超限）

    Note over API,TM: 创建会话
    API->>TM: invoke(query, thread_id?)
    alt 新会话
        TM->>TM: 生成新 thread_id
        TM->>CP: 创建会话状态
        API->>API: 创建 sessions 记录
    else 续接会话
        API->>API: 校验会话所有权
        TM->>TM: 清理旧状态
    end
    API-->>F: 201 {thread_id, session_id}

    Note over F,LLM: 第2步：SSE 流式消费
    F->>API: GET /chat/stream/{thread_id} (SSE)

    Note over TM,AG: 第3步：Agent 启动
    TM->>AG: 构建 Agent（含动态 KB 注入）
    AG->>AG: 查询 knowledge_bases 表
    AG->>AG: 构建 system prompt
    AG->>AG: astream_events 开始

    Note over AG,LLM: 第4步：工具调用（知识检索）
    AG->>AG: LLM 判断需要检索
    AG->>AG: 调用 retrieve_knowledge 工具

    EM->>AG: 推送 tool_call 事件到 Queue
    F-->>API: 收到 tool_call 事件
    F->>F: 显示"正在检索..."

    AG->>EM: embed(query)
    EM->>QD: search(query_vector, query_text)
    QD->>QD: Dense Prefetch（语义检索）
    QD->>QD: Sparse Prefetch（关键词检索）
    QD->>QD: RRF 融合排序
    QD->>QD: score_threshold 过滤 + kb_name 过滤
    QD-->>AG: 返回格式化结果

    Note over AG,LLM: 第5步：LLM 流式生成
    AG->>AG: 推送 tool_result 事件到 Queue
    F-->>API: 收到 tool_result 事件
    F->>F: 收起工具调用提示

    AG->>LLM: 注入检索结果 + 对话历史
    LLM-->>AG: 流式生成 token
    loop 每个 token
        AG->>AG: 推送 token 事件到 Queue
        F-->>API: 收到 token 事件
        F->>F: 增量渲染到界面
    end

    Note over AG,CP: 第6步：状态持久化
    AG->>CP: 保存对话状态（checkpoint）
    CP-->>AG: 确认
    AG->>AG: 推送 done 事件到 Queue
    F-->>API: 收到 done 事件
    F->>F: 完成渲染，启用输入框
```

## 注册与登录流程

```mermaid
sequenceDiagram
    actor U as 用户
    participant F as 前端
    participant API as FastAPI
    participant DB as MySQL
    participant ST as Security(bcrypt/JWT)

    Note over U,ST: 注册流程
    U->>F: 填写邮箱 + 密码
    F->>API: POST /auth/register {email, password}
    API->>API: 邮箱格式校验
    API->>DB: 查询邮箱是否已注册
    DB-->>API: 未注册
    API->>ST: hash_password(password)
    ST-->>API: bcrypt hash
    API->>DB: INSERT users
    DB-->>API: 创建成功
    API-->>F: 201 {id, email}
    F-->>U: 注册成功，跳转到登录

    Note over U,ST: 登录流程
    U->>F: 填写邮箱 + 密码
    F->>API: POST /auth/login {email, password}
    API->>DB: 查询用户
    DB-->>API: 用户数据
    API->>ST: verify_password(plain, hash)
    ST-->>API: 验证通过
    API->>ST: create_access_token(user_id)
    ST-->>API: JWT Token (7天有效)
    API-->>F: 200 {access_token, token_type, user}
    F->>F: 存储 token 到 localStorage
    F-->>U: 跳转到聊天页面
```

## 知识库管理流程

```mermaid
flowchart TD
    %% 创建知识库
    U1[用户] -->|创建知识库| CreateKB[POST /knowledge/bases]
    CreateKB -->|校验名称唯一| CheckName{名称已存在?}
    CheckName -->|是| Error409[409 冲突]
    CheckName -->|否| InsertKB[INSERT knowledge_bases]
    InsertKB -->|创建磁盘目录| MkDir[mkdir knowledges/<name>/]
    MkDir --> ReturnKB[返回知识库信息]

    %% 上传文档
    U2[用户] -->|上传文档| Upload[POST /knowledge/upload]
    Upload -->|校验类型| CheckExt{扩展名<br>.md / .txt?}
    CheckExt -->|否| Error400[400 不支持]
    CheckExt -->|是| CheckSize{文件大小<br>≤ 10MB?}
    CheckSize -->|否| ErrorSize[400 文件过大]
    CheckSize -->|是| SaveFile[保存文件到磁盘]
    SaveFile -->|创建记录| CreateDoc[INSERT knowledge_docs<br>status=processing]
    CreateDoc -->|后台任务| Background[BackgroundTasks]
    Background --> Parse[parse_document 解析]
    Parse --> Split[text_splitter 分块]
    Split --> Embed[embed_batch 嵌入]
    Embed --> Upsert[Qdrant upsert]
    Upsert --> UpdateStatus[UPDATE status=ready]

    UpdateStatus -->|前端轮询| Poll[前端轮询 /knowledge/list]

    %% 删除文档
    U3[用户] -->|删除文档| Delete[DELETE /knowledge/{doc_id}]
    Delete --> DeleteVector[Qdrant 删除向量]
    DeleteVector --> DeleteFile[删除磁盘文件]
    DeleteFile --> DeleteDB[DELETE knowledge_docs]
```

## 问答对话流程

```mermaid
flowchart TD
    Start[用户输入问题] --> Validate{≤ 500 字?}

    Validate -->|否| Return400[400 错误]

    Validate -->|是| RateLimit{每日限额<br>未超限?}
    RateLimit -->|否| Return429[429 频率超限]

    RateLimit -->|是| SessionType{新会话<br>或续接?}

    SessionType -->|续接| Verify[校验会话所有权]
    Verify -->|通过| CreateTask[创建后台 Task]
    Verify -->|不通过| Return404[404 会话不存在]

    SessionType -->|新会话| NewSession[创建 sessions 记录]
    NewSession --> CreateTask

    CreateTask --> BuildAgent[构建 Agent]

    BuildAgent --> QueryKB[查询 knowledge_bases]
    QueryKB --> BuildPrompt[构建 system prompt<br>含 KB 列表 + 路由信息]
    BuildPrompt --> RunAgent[运行 Agent]

    RunAgent --> LLMDecide{LLM 判断<br>是否需要检索?}
    LLMDecide -->|闲聊/问候| DirectResponse[直接生成回答]

    LLMDecide -->|产品问题| CallTool[调用 retrieve_knowledge]

    CallTool --> Embed[Embedding 查询]
    Embed --> DenseSparse[双路检索<br>Dense + Sparse]
    DenseSparse --> RRF[RRF 融合排序]
    RRF --> ScoreCheck{score ≥ 0.7?}

    ScoreCheck -->|无符合结果| EmptyResult[返回空]
    ScoreCheck -->|有结果| FormatResults[格式化检索结果]

    FormatResults --> Inject[注入检索结果到 LLM]
    EmptyResult --> Inject

    Inject --> LLMGenerate[LLM 生成回答]
    DirectResponse --> LLMGenerate

    LLMGenerate --> StreamSSE[SSE 流式输出 token]
    StreamSSE --> Complete[回答完成]

    Complete --> Checkpointer[保存对话状态<br>到 Checkpointer]
    Checkpointer --> End[对话结束<br>等待用户下一轮]

    Note[注：Agent 可以在<br>结果不充分时<br>多次调用检索工具]
```

## 反馈评价流程

```mermaid
sequenceDiagram
    actor U as 用户
    participant F as 前端
    participant API as FastAPI
    participant DB as MySQL

    Note over U,DB: 提交评价
    U->>F: 点击点赞/点踩按钮
    F->>F: 更新本地状态（乐观更新）
    F->>API: POST /feedback {message_id, rating, comment?}

    API->>DB: 查询 (user_id, message_id) 是否已有评价

    alt 无已有评价
        DB-->>API: 未找到
        API->>DB: INSERT feedback
        DB-->>API: 创建成功
        API-->>F: 201 {id, message_id, rating, comment}
    else 已有相同 rating
        DB-->>API: 找到评价
        API->>DB: DELETE feedback（取消评价）
        DB-->>API: 删除成功
        API-->>F: 204 No Content
        F->>F: 恢复按钮到未选中状态
    else 已有不同 rating
        DB-->>API: 找到评价（rating 不同）
        API->>DB: UPDATE rating（切换 like/dislike）
        DB-->>API: 更新成功
        API-->>F: 200 {id, message_id, new_rating, comment}
    end

    Note over U,DB: 加载历史会话时
    F->>API: GET /session/{thread_id}
    API->>DB: 查询所有消息
    API->>DB: 查询用户对这些消息的评价
    DB-->>API: 评价列表
    API->>F: 消息中附带 user_rating 字段
    F->>F: 恢复按钮选中状态
    F-->>U: 显示历史评价状态
```

## 会话管理流程

```mermaid
flowchart LR
    %% 会话列表
    U1[用户] -->|查看会话列表| List[GET /session/list]
    List -->|按 user_id 查询| QuerySession[SELECT sessions<br>WHERE user_id=?<br>ORDER BY updated_at DESC]
    QuerySession -->|返回列表| ReturnList[会话列表<br>含 thread_id, title, 时间]

    %% 加载历史会话
    U2[用户] -->|点击历史会话| Load[GET /session/{thread_id}]
    Load -->|校验会话所有权| CheckOwner{属于当前用户?}
    CheckOwner -->|否| ReturnErr[404]
    CheckOwner -->|是| GetState[aget_state(thread_id)]
    GetState -->|从 Checkpointer 恢复| ParseMsgs[解析消息列表]
    ParseMsgs -->|提取消息 ID| QueryFb[查询用户评价]
    QueryFb -->|合并评价数据| ReturnDetail[返回完整对话记录<br>含消息列表 + 评价状态]

    %% 删除会话
    U3[用户] -->|删除会话| Delete[DELETE /session/{thread_id}]
    Delete --> StopTask[停止运行中的 Agent 任务]
    StopTask --> DeleteCP[删除 Checkpointer 数据]
    DeleteCP --> DeleteDB[DELETE sessions 记录]
    DeleteDB --> Return204[204 No Content]

    %% 自动删除反馈数据说明
    Note[说明：feedbacks 表<br>通过 message_id 关联，<br>不随会话删除级联<br>以保持反馈数据完整性]
